# Digital tools can shift memory from content recall toward access-location recall.

## Summary

The 2011 Science paper on the Google effect found that expected access to information can reduce recall of the information itself while improving recall of where it can be found.

## Scores

- Evidence strength: 76.0
- Relevance: 84.0
- Source credibility: 86.0

## Source

- Title: Google Effects on Memory: Cognitive Consequences of Having Information at Our Fingertips
- Publisher: Science
- Authors: Betsy Sparrow, Jenny Liu, Daniel M. Wegner
- URL: https://www.science.org/doi/10.1126/science.1207745
- Language: en

## Limitations

This predates modern LLMs and search-based behavior is not the same as conversational AI delegation, so it should be used as background theory.
